# Changelog

## v0.3.0 — 2025

- Arrays with full index access, mutation, and nested array support (`vibe arr[] = [1,2,3]`)
- Compound assignment operators (`+=`, `-=`, `*=`, `/=`)
- Logical operators (`&&`, `||`, `nah`)
- `ghosted` null type
- PEMDAS/BODMAS operator precedence
- Integer division operator (`\`)
- Line numbers in all error messages
- `floatify` and `intify` builtins (replacing `numify`)
- Fixed scope bug where functions couldn't call other functions
- Fixed negative number parsing
- Array builtins: `push`, `pop`, `len`

## v0.2.3 — 2025

- Updated readme and documentation

## v0.2.2 — 2025

- Released SlayLang CLI and npm package
- Automatic VS Code extension installer via `slay setup`

## v0.2.1 — 2025

## v0.2.0 — 2025

- VS Code extension with syntax highlighting and autocompletion for `.slay` files
- Automatic release script
- CLI command via `slay`

## v0.1.0 — 2025

- Lexer, parser, and evaluator
- Variables (`vibe`, `lockedin`)
- Functions (`cook`, `yeet`)
- Conditionals (`sus`, `mid`, `tho`)
- Loops (`grind`, `spin`)
- `break` (`dip`) and `continue` (`skip`)
- Booleans (`nocap`, `cap`)
- Builtins: `yap`, `rant`, `snoop`, `numify`
- For loop, while loop
- Recursion
